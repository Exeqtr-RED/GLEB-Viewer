# GLEB Viewer — F3D Embedded Edition

Просмотрщик 3D-моделей с деревом директорий, автоматически подбирающим HDRI-окружение по категории модели. Построен на PySide6 + F3D 3.5.0 с offscreen-рендерингом.

## Возможности

- **Дерево моделей** — иерархический обзор папок с .glb файлами, поиск с поддержкой кириллицы и транслитерации, сортировка по имени/размеру/дате
- **Встроенный 3D-просмотр** — offscreen-рендеринг через libf3d, управление камерой мышью (вращение, масштабирование, панорамирование) с инерцией
- **Авто-HDRI** — HDRI-карта подбирается автоматически по названию папки (kosmos → space.hdr, voda → lakeside_4k.hdr, и т.д.)
- **Превью и reference** — одиночный клик по папке показывает картинку из `preview/`, двойной клик по `reference/` открывает горизонтальную галерею
- **Теги** — система тегов для моделей и папок с наследованием (тег папки применяется ко всем файлам внутри), фильтрация по тегам, сохранение в JSON
- **Пакетный менеджер** — массовое создание скриншотов для всех моделей с выбором разрешения (512/1024/2048)
- **Анимация** — воспроизведение, остановка, настройка скорости (0.25x–4x)
- **Темы** — 6 встроенных тем (по умолчанию, тёмная, светлая, синяя, Astra Deep, Astra Z.ai)
- **Настраиваемые шрифты** — раздельный размер шрифта для дерева моделей (7–14 пт) и меню (7–14 пт)
- **Drag & Drop** — перетаскивание файлов напрямую в окно
- **Скрытие reference** — пункт меню «Вид → Скрывать reference» для скрытия папок reference в дереве
- **Настройки F3D** — полный диалог настроек рендеринга (raytracing, AA, пост-эффекты), сцены (HDRI, сетка, оси), модели (wireframe, normal glyphs, volume), с сохранением/загрузкой пресетов
- **Сохранение состояния** — последняя папка, тема, размер шрифтов, скрытие reference сохраняются между запусками через QSettings

## Установка

### Требования

- Python 3.10+
- Windows / Linux / macOS
- Видеокарта с поддержкой OpenGL

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Exeqtr-RED/GLEB-Viewer.git
cd GLEB-Viewer

# 2. Создать виртуальное окружение
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запуск
python main.py
```

### Проверка установки

```bash
python -c "import f3d; print('f3d', f3d.__version__)"
python -c "import PySide6; print('PySide6', PySide6.__version__)"
python -c "import numpy; print('numpy', numpy.__version__)"
```

| Меню | Пункт | Описание |
|---|---|---|

| | Настройки F3D... | Диалог с 4 вкладками: рендеринг, сцена, модель, конфиги |
| **Вид** | Тема | Выбор из 6 тем оформления |
| | Шрифт дерева | Размер шрифта дерева моделей (7–14 пт) |
| | Шрифт меню | Размер шрифта меню (7–14 пт) |
| | Скрывать reference | Скрыть/показать папки `reference/` в дереве |
| **Анимация** | Воспроизвести / Пауза | Переключить анимацию (Space) |
| | Остановить и сбросить | Остановить анимацию |
| | Скорость | 0.25x, 0.5x, 1x, 2x, 4x |
| **Пакетный менеджер** | Создать скриншоты всех моделей | Массовый рендер с выбором разрешения |
| **Справка** | О программе | Информация о версии и ссылка на автора |

### Дерево моделей

- **Клик по файлу .glb** — загрузить 3D-модель в просмотрщик
- **Одиночный клик по папке** — показать превью из `preview/` (если внутри есть изображения)
- **Двойной клик по папке** — раскрыть/свернуть; для `reference/` — открыть горизонтальную галерею картинок
- **Ctrl+- / Ctrl++** — свернуть/развернуть текущий узел дерева
- **ПКМ по файлу** — контекстное меню: открыть в проводнике, копировать имя/путь/полный путь, управление тегами
- **ПКМ по папке** — контекстное меню: копировать путь, управление тегами папки
- **Поиск** — поддерживает кириллицу и транслитерацию (например, «космос» найдёт «kosmos», и наоборот)
- **Сортировка** — по имени, размеру файлу, дате изменения; направление: по возрастанию / убыванию
- **Теги** — кнопка «Теги...» открывает окно управления: добавление/удаление тегов, фильтрация моделей по тегу

### 3D-просмотрщик

Управление камерой через мышь:

| Действие | Управление |
|---|---|
| Вращение | ЛКМ (левая кнопка) + движение мыши |
| Панорамирование | СКМ (колёсико) или ПКМ + движение мыши |
| Масштабирование | Колёсико мыши |
| Точность (медленнее) | Зажать Shift при любом действии |

Управление камерой через клавиатуру:

| Клавиша | Действие |
|---|---|
| W / Стрелка вверх | Наклон камеры вверх |
| S / Стрелка вниз | Наклон камеры вниз |
| A / Стрелка влево | Поворот камеры влево |
| D / Стрелка вправо | Поворот камеры вправо |
| Q | Панорамирование влево |
| E | Панорамирование вправо |
| R | Сброс камеры |
| + / = | Приблизить |
| - | Отдалить |

### HDRI-маппинг

Имя папки в пути к модели автоматически определяет HDRI-окружение:

| Папка | HDRI | Описание |
|---|---|---|
| `kosmos` | space.hdr | Космическое пространство |
| `voda` | lakeside_4k.hdr | Озёрная панорама |
| `vozduh` | sky_4k.hdr | Небо |
| `zemlya` | land_4k.hdr | Земной ландшафт |

Маппинг регистронезависимый — папки `Kosmos`, `KOSMOS`, `kosmos` одинаково сработают.

### Настройки F3D

Диалог настроек содержит 4 вкладки:

1. **Рендеринг** — raytracing (вкл/выкл, denoise, сэмплы), пост-эффекты (AO, tone mapping, AA с выбором режима, depth peeling, translucency), фон (skybox, размытие, цвет, отображение глубины)
2. **Сцена** — HDRI ambient, интенсивность света, сетка (вкл/выкл, абсолютная, деления), оси координат, направление «верх», инверсия зума
3. **Модель** — шахматный текстурный фон, нормали, скелет (armature), точечные спрайты (тип, размер, абсолютный), volume rendering, SciVis
4. **Конфиги** — сохранение/загрузка/удаление пресетов, экспорт/импорт JSON-файлов настроек

### Пакетный менеджер

Создаёт скриншоты всех моделей из дерева и сохраняет их в подпапку `preview/` рядом с каждым файлом. Доступные разрешения: 512x512, 1024x1024, 2048x2048. Скриншоты создаются с текущими настройками F3D (raytracing, HDRI и т.д.).

### Теги

- Теги назначаются как отдельным файлам, так и целым папкам
- Тег папки автоматически наследуется всеми файлами внутри неё
- Фильтрация по тегу из окна управления или через контекстное меню
- Теги сохраняются в `tags.json` в корне проекта

## Поддерживаемые форматы

glTF/GLB, FBX, OBJ, STL, PLY, VTK, ABC, USD, 3DS, DAE, PBRt и другие (через VTK). Форматы, не поддерживаемые движком, автоматически пропускаются с сообщением в консоль.

## Сборка в EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico --add-data "themes;themes" --add-data "hdri;hdri" --add-data "icons;icons" --add-data "configs;configs" --hidden-import=f3d main.py
```

Готовый исполняемый файл появится в `dist/`. Для корректной работы рядом с EXE должны находиться папки `themes/`, `hdri/`, `icons/`, `configs/`.

## Архитектура

```
┌───────────────────────────────────────────────────────┐
│  MainWindow (QMainWindow)                             │
│  ┌────────────────┬──────────────────────────────┐    │
│  │  ModelTree     │  F3DWidget (offscreen)       │    │
│  │  (QWidget)     │  ┌────────────────────────┐  │    │
│  │                │  │  libf3d engine         │  │    │
│  │  - Поиск       │  │  (render_to_image)     │  │    │
│  │  - Сортировка  │  └────────────────────────┘  │    │
│  │  - Теги        │  + камера (az/el/dist)      │    │
│  │  - Фильтр      │  + оверлей превью/           │    │
│  │  - Превью      │    reference-галереи         │    │
│  │  - Контекст.   │                              │    │
│  └────────────────┴──────────────────────────────┘    │
│  + QSplitter, QMenuBar, QStatusBar                     │
│  + QSettings (персистентность)                        │
└───────────────────────────────────────────────────────┘
```

- **F3DWidget** — рендерит кадры через `libf3d` в offscreen-буфер и отображает через `QPainter` на виджете PySide6
- **Камера** — управляется сферическими координатами (azimuth, elevation, distance) с инерцией и затуханием
- **ModelTree** — иерархическое дерево с рекурсивной фильтрацией, транслитерацией кириллицы, поддержкой тегов с наследованием от папок
- **QSettings** — настройки пользователя (последняя папка, тема, шрифты, скрытие reference) сохраняются между запусками
